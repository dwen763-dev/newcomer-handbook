# 看懂工资条：钱是怎么少的？

> 核实日期：2026-10-27 · 依据：《工资支付暂行规定》（劳部发〔1994〕489 号）、《中华人民共和国个人所得税法》（2018 年修正）、《中华人民共和国社会保险法》（2018 年修正）、《中华人民共和国劳动法》（2018 年修正）

## 照着看：一张工资条从上到下

| 项目 | 是什么 | 你要核对什么 |
|---|---|---|
| **应发工资** | 基本工资 + 绩效 + 补贴 + 加班费等 | 和劳动合同、offer 约定的对得上吗 |
| − 个人社保 | 养老、医疗、失业保险的**个人部分** | 有没有每月都扣；扣了就应该真的交上了，可以去查 |
| − 个人公积金 | 住房公积金的**个人部分** | 公积金账户里有没有对应的入账 |
| − 个人所得税 | 单位**代扣代缴**的个税 | 个人所得税 App 里能查到单位为你申报的收入和已扣税款 |
| **实发工资** | 打到你卡里的钱 | 和银行到账一致吗 |

> 记住一句：**应发减"三项代扣"等于实发，其余的扣款要有依据。**

## 单位能从工资里扣什么
按《工资支付暂行规定》第十五条，用人单位**不得克扣**劳动者工资。可以**代扣**的只有：
1. 代扣代缴的个人所得税；
2. 代扣代缴的应由劳动者个人负担的各项社会保险费用；
3. 法院判决、裁定中要求代扣的抚养费、赡养费；
4. 法律、法规规定可以从劳动者工资中扣除的其他费用。

## 工资条是你的权利
- 用人单位在支付工资时，**应当向劳动者提供一份其个人的工资清单**。
- 社保：用人单位应当**按月将缴纳社会保险费的明细情况告知本人**。
- 个税：扣缴义务人应当**向纳税人提供其个人所得和已扣缴税款等信息**。

## 工资什么时候发
- 工资**至少每月支付一次**，在约定的日期支付；遇节假日或休息日，提前在最近的工作日支付。
- 拖欠或者未足额支付的，处理办法见[劳动仲裁怎么申请](../07-离职与维权/劳动仲裁怎么申请.md)。

## 依据（原文摘录）

**《工资支付暂行规定》第六条（节选）**
> 用人单位必须书面记录支付劳动者工资的数额、时间、领取者的姓名以及签字，并保存两年以上备查。用人单位在支付工资时应向劳动者提供一份其个人的工资清单。

**《工资支付暂行规定》第七条**
> 工资必须在用人单位与劳动者约定的日期支付。如遇节假日或休息日，则应提前在最近的工作日支付。工资至少每月支付一次，实行周、日、小时工资制的可按周、日、小时支付工资。

**《工资支付暂行规定》第十五条**
> 用人单位不得克扣劳动者工资。有下列情况之一的，用人单位可以代扣劳动者工资：（一）用人单位代扣代缴的个人所得税；（二）用人单位代扣代缴的应由劳动者个人负担的各项社会保险费用；（三）法院判决、裁定中要求代扣的抚养费、赡养费；（四）法律、法规规定可以从劳动者工资中扣除的其他费用。

**《劳动法》第五十条**
> 工资应当以货币形式按月支付给劳动者本人。不得克扣或者无故拖欠劳动者的工资。

**《社会保险法》第六十条第一款（节选）**
> 职工应当缴纳的社会保险费由用人单位代扣代缴，用人单位应当按月将缴纳社会保险费的明细情况告知本人。

**《个人所得税法》第十条第二款**
> 扣缴义务人应当按照国家规定办理全员全额扣缴申报，并向纳税人提供其个人所得和已扣缴税款等信息。

来源：[中国政府网](https://www.gov.cn/zhengce/2022-08/31/content_5711284.htm)《工资支付暂行规定》（劳部发〔1994〕489 号，1995-01-01 施行）；[国家法律法规数据库](https://flk.npc.gov.cn)《中华人民共和国劳动法》《中华人民共和国社会保险法》（2018-12-29 修正）、《中华人民共和国个人所得税法》（2018-08-31 修正）
